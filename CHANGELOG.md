# История изменений

Версии указаны по файлу `VERSION`. До его появления версия не назначалась; Git-тегов выпусков пока нет.

## 0.1.6 — готовится

- Добавлен выбор службы кнопкой при выдаче подключения пользователю.
- Управление qWDTT и библиотека VK-хешей перенесены в раздел «Службы»; Free TURN сохранён отдельно.

## 0.1.5

- При установке запрашивается домен или IP, настраивается HTTPS и выводятся адрес и учётные данные панели.
- Исправлен ввод адреса через терминал при установке через curl на Python 3.14.
- Установщик показывает этапы установки, обновления и настройки HTTPS, а также вывод системных команд в консоли.
- Исправлена команда установки для интерактивного ввода при запуске sudo с псевдотерминалом.
- Для новых подключений автоматически формируется название по протоколу; для VLESS добавляются Network и SELF.
- Страна сервера определяется по IP через локальную базу DB-IP Lite, а её флаг добавляется к названию. Код страны можно исправить вручную.

## 0.1.4

- Установщик добавляет недостающие зависимости на Debian/Ubuntu и проверяет компоненты системы.
- Шаблон HTTPS совместим с nginx, поддерживающим HTTP/2 в директиве listen.

## 0.1.3

- Исправлено выравнивание формы входа на широких экранах.
- Для OpenFlux добавлено автоматическое создание комнат cups.online без учётной записи.
- Новые службы получают названия по протоколу; у VLESS добавляются Network и отметка SELF для self-SNI.
- Исправлен запуск транспорта Hysteria в Xray: ключ авторизации создаётся и передаётся клиенту автоматически.

## 0.1.2

- Панель переименована в panel for YPtun; обновлены оформление, цветовая палитра и типографика.
- Улучшена мобильная навигация: доступны все разделы и выход из панели.
- Подключения остановленных служб исключаются из подписок и возвращаются после запуска без смены ключей.

## 0.1.1 — 2026-11-15

- Добавлены QR-коды, копирование и скачивание профилей и подписок. Содержимое скрыто до явного показа; QR создаётся локально.
- При обновлении штатной конфигурации nginx добавляется недостающий маршрут `/subscription/` с проверкой и возможностью отката.
- Добавлены тесты обмена профилями и обновления конфигурации nginx.

## 0.1.0 — 2026-11-15

Коммит `350584d` (`deploy`).

- Добавлены версия панели и отображение ревизии Git.
- Добавлены установка и обновление через curl, резервирование базы и предыдущих исходников, проверка запуска и откат при ошибке.
- На странице обзора добавлены состояние CPU, памяти, диска, время работы и load average.

## Без версии — 2026-11-15

Коммит `7297934` (`init`).

- Первоначальная версия панели: управление VPN-службами, пользователями и подписками, генерация конфигураций и работа с Docker.
- Добавлены веб-интерфейс, аутентификация, инструменты развёртывания и тесты.
