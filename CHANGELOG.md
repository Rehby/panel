# История изменений

Версии указаны по файлу `VERSION`. До его появления версия не назначалась; Git-тегов выпусков пока нет.

## 0.1.11 — 2026-11-17

- При открытии раздела «Образы» запускается фоновая проверка новых версий. Автоматическая проверка каждого образа кешируется на 24 часа, включая ошибки; ручная проверка обходит кеш.
- Добавлены уведомление и счётчик доступных обновлений, кнопки проверки одного или всех образов и кнопка «Обновить» на карточке.
- Для Xray и sing-box проверяются новые стабильные версии; для образов с тегом latest — digest в реестре; для локальных сборок — новые ревизии исходников.
- Проверки и выбранные версии сохраняются между перезапусками панели. Обновление скачивает проверенный digest или собирает зафиксированную ревизию; работающие службы применяют образ после перезапуска.
- Собственные образы служб сохраняются. Неудачная сборка не меняет выбранную версию. Проверка реестров поддерживает Docker без дополнительного плагина Buildx.

## 0.1.10 — 2026-11-17

- Исправлен HTTP Host при чтении метрик WebProxy через Unix-сокет: сервер больше не отклоняет запрос с HTTP 400.
- Соединения SQLite закрываются после каждой операции, включая ошибки. Устранено исчерпание файловых дескрипторов и последующие ошибки открытия базы при длительной работе панели.
- Общий трафик пользователя явно подписан; расход отдельных подключений показан в их списке. Для WebProxy добавлена кнопка «Telegram», а пустая подписка YPtun скрыта у владельцев только Telegram-доступов.

## 0.1.9 — 2026-11-17

- Для WDTT/qWDTT добавлен учёт трафика из полей `up_bytes` и `down_bytes` штатного API qWDTT 1.4.3 по схеме WDTT Control Panel: текущие счётчики ядра и накопление их прироста в SQLite.
- Добавлены показатели «Сегодня» и «Всё время», а также текущий счётчик движка. Сброс расхода для лимита сохраняет эти показатели; исторический расход при первом подключении WDTT не записывается целиком в сегодняшний день.
- Сохранённые в ядре счётчики WDTT не учитываются повторно после перезапуска. Смена пароля и уменьшение счётчиков ядра обрабатываются как новый отсчёт.
- Лимит WDTT отключает пароль через API без перезапуска службы и отключения остальных пользователей. Снятие блокировки сохраняет ручной отзыв доступа; новые доступы заблокированного владельца сразу деактивируются.
- Трафик отдельных TURN-подключений отображается в разделе «Службы». Для включения статистики WDTT пересборка образа не требуется.

## 0.1.8 — 2026-11-17

- При установке автоматически собираются образы из закреплённых исходников и скачиваются готовые образы. Повторная сборка и скачивание доступны в разделе «Образы».
- В дополнительных настройках службы можно указать собственный Docker-образ; пустое значение возвращает стандартный образ.
- Добавлены накопительная статистика отправленного и полученного трафика, общий лимит пользователя в ГиБ и ручной сброс расхода.
- Учёт доступен для Telegram WebProxy, VLESS, VMess, Trojan, Shadowsocks, управляемого WARP и автоматически настроенных WireGuard, AmneziaWG и Free TURN. Для остальных движков отображается отсутствие учёта; лимит для пользователя с такими подключениями недоступен.
- При достижении лимита ключи исключаются из конфигураций и подписок. Сброс расхода или увеличение лимита снимает блокировку; отключённые вручную доступы не включаются.
- Расход сохраняется в SQLite при перезапуске панели и пересоздании контейнеров. Ошибки статистики и применения лимита отображаются в интерфейсе; применение лимита повторяется автоматически.
- Блок состояния сервера перенесён в самое начало главной страницы.

## 0.1.7 — 2026-11-17

- Добавлен Telegram WebProxy с транспортом HTTPS / WebSocket и отдельным secret для каждого доступа.
- В профиле подключения доступны ссылка `tg://webproxy?server=...&secret=...`, кнопка «Добавить в Telegram», копирование и QR-код.
- WebProxy исключён из общей подписки YPtun и индивидуальных подписок `/sub/`.
- Добавлены изменение и отзыв secret; при отзыве последнего доступа служба останавливается.
- На установленной Linux-панели автоматически настраиваются сертификат Let's Encrypt и отдельный домен nginx с поддержкой WebSocket. Внутренний порт доступен только через localhost.
- Добавлена закреплённая сборка Docker-образа Telegram WebProxy в разделе «Образы».

## 0.1.6

- Добавлено управление составом подключений пользователя галочками.
- VK-ссылки qWDTT задаются для службы и обновляются у всех её пользователей.
- TLS-службы по умолчанию используют сертификат панели с обновлением при продлении.
- Управление qWDTT и библиотека VK-хешей перенесены в раздел «Службы»; Free TURN сохранён отдельно.

## 0.1.5

- Установщик показывает этапы установки, обновления и настройки HTTPS, а также вывод системных команд в консоли.
- Исправлена команда установки для интерактивного ввода при запуске sudo с псевдотерминалом.
- Для новых подключений автоматически формируется название по протоколу; для VLESS добавляются Network и SELF.
- Страна сервера определяется по IP через локальную базу DB-IP Lite, а её флаг добавляется к названию. Код страны можно исправить вручную.
